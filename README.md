# 🎭 Генератор промптов: Юмористические семейные истории

Веб-приложение для генерации подробных промптов для написания юмористических рассказов о российских семьях. Создано для авторов каналов на Дзене и других платформах.

---

## 🌐 Демо

👉 [Открыть генератор](https://stratig006-gif.github.io/humor-prompt-generator/)

---

## 📋 Что делает генератор

Вы выбираете параметры истории — генератор собирает подробный промпт, который можно отправить в Gemini или Claude одной кнопкой. ИИ напишет готовый юмористический рассказ по вашим параметрам.

---

## 🎛 Параметры истории

| Параметр | Вариантов | Описание |
|---|---|---|
| 🏠 Фамилия семьи | 30 | Смешные говорящие фамилии |
| 📍 Место действия | 125 | Города, пригороды, сёла, деревни |
| 👨 Профессия мужа | 107 | От сварщика до дирижёра |
| 👩 Профессия жены | 103 | От балерины до криптотрейдера |
| 👶 Состав детей | 9 | От одного ребёнка до трёх |
| 👴 Гость | 20 | Колоритные родственники |
| 🌦 Погода | 30 | От январского мороза до майского снегопада |
| 🎬 Ситуация | 100 | Комические завязки |
| 📏 Длина | 3 | Короткая / Средняя / Длинная |

**Итого: более 22 триллионов уникальных комбинаций**

---

## 📏 Варианты длины рассказа

- **Короткая** — 6-9 минут чтения, 3000-3500 слов
- **Средняя** — 11-12 минут чтения, 4500-5000 слов
- **Длинная** — 15-17 минут чтения, 6000-6500 слов

---

## ✨ Возможности

- **Ручной выбор** — выберите каждый параметр самостоятельно
- **🎲 Случайный выбор** — все параметры заполняются случайно одной кнопкой
- **📋 Скопировать** — копирует промпт в буфер обмена
- **🚀 Открыть в Gemini** — копирует промпт и открывает Gemini
- **✦ Открыть в Claude** — копирует промпт и открывает Claude

---

## 🧠 Как устроен промпт

Каждый сгенерированный промпт содержит:

- Полный состав семьи с характерами каждого ребёнка (уникальные черты, без повторений)
- Жёсткое требование к объёму текста (с тройным напоминанием для ИИ)
- Подробный внутренний план из 8 частей — структура задаётся модели, но **не отображается** в финальном рассказе
- Запрет на подзаголовки и markdown-разметку в выводе — рассказ выходит цельным текстом
- Акцент на контраст профессий мужа и жены как главный комический двигатель
- Требование к погоде и месту органично влиять на сюжет

## 🚀 Запуск локально

Просто откройте `index.html` в браузере — никаких зависимостей и сборки не требуется.

```
humor-prompt-generator/
├── index.html   — разметка и структура
├── script.js    — данные, логика, генерация промпта
├── styles.css   — оформление
└── README.md    — этот файл
```
